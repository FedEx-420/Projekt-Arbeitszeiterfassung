# Arbeitszeit 2026 – App

Diese App ist eine installierbare, offline nutzbare Web-App (PWA) für Android und iPhone. Die öffentliche Version startet bewusst ohne Kunden- und Arbeitszeitdaten.

## Kostenlos veröffentlichen

Die Dateien dieses Ordners lassen sich ohne Anpassung auf **GitHub Pages** veröffentlichen:

1. Kostenloses GitHub-Konto öffnen und ein neues Repository anlegen.
2. Alle Dateien aus diesem Ordner hochladen.
3. Unter **Settings → Pages** bei „Deploy from a branch“ die Branch main und den Ordner /(root) auswählen.
4. Den angezeigten Link auf dem Smartphone öffnen.

Android: Im Browser „App installieren“ auswählen.  
iPhone: In Safari auf „Teilen“ → „Zum Home-Bildschirm“ tippen.

Die Erfassung funktioniert anschließend offline. Über „Sicherung“ kann jederzeit eine JSON-Datei exportiert und später wieder importiert werden. So bleiben persönliche Kundendaten ausschließlich auf dem jeweiligen Gerät.
