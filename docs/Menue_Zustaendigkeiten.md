# Zuständigkeiten der Menüs ab v1005

Eigenständige Funktionen werden ausschließlich im zugehörigen Menü angezeigt und bearbeitet. Die Hauptnavigation enthält jedes erlaubte Ziel einmal. Die Sichtbarkeit bleibt an Rolle und Betrieb gebunden.

Ab v1006 bleibt bei einem Wechsel des Einkaufszugangs der aktuelle Bereich erhalten.
Wer im Warenkorb von Neugart zu FiF wechselt, sieht weiterhin nur den Warenkorb.
Die zusätzlichen Such-/Warenkorb-Wechselbuttons im Seiteninhalt entfallen; dafür
werden ausschließlich die vorhandenen Hauptmenüs Einkauf und Warenkorb verwendet.
Der allgemeine Warenkorb heißt auch in der Seitenüberschrift Warenkorb.

| Menü | Zuständige Funktion |
| --- | --- |
| Übersicht | Tagesübersicht; keine Firmen- oder Export-Einrichtung |
| Arbeitsscheine | Arbeitsscheine erstellen und bearbeiten |
| Kunden | Kundenstammdaten und kundenspezifische Konditionen |
| Planung | Aufträge und Termine planen |
| Kalender | Kalenderansicht und Abwesenheiten |
| Angebote | Angebotsentwürfe und deren Positionen |
| Materialliste | Materialien, Artikelpreise und Gruppenverwaltung |
| Katalog hinzufügen | Katalogdateien einlesen, prüfen und übernehmen |
| Fachhändler Kataloge | Gespeicherte Originalkataloge verwalten |
| Einkauf | Artikel suchen, auswählen und Favoriten verwenden |
| Warenkorb | Mengen bearbeiten und bestätigte Händlerübergabe starten |
| Offene Arbeitsscheine | Auswahl für eine neue Rechnung |
| Erstellte Rechnungen | Ausgestellte Dokumente und Korrekturverfahren |
| DATEV-Export | Export-Einrichtung, Buchungsentwürfe, Exporte und deren Historie |
| DATEV → Verfahrensdokumentation | Vorhandenes accounting-Dokument mit Versionshistorie und Prüfvermerken |
| Firmendaten & Unterlagen | Firmen-/Steuerstammdaten und die fünf nicht buchhalterischen Dokumentarten |
| Einstellungen | Benutzer, Team, Geräte und gespeicherte Händlerzugänge |
| Postfach | Nachrichten und Anhänge |
| Anbieteradministration | Geschäftskonten und Anbieter-Konfiguration |

Belegbezogene Rechnungsangaben, Kunden-/Materialauswahl und Rückwege innerhalb eines Arbeitsablaufs sind keine zweite Stammdatenverwaltung. Bereits ausgestellte Dokumente, exakte Preise, Login-Firmennamen und rechtliche Firmennamen bleiben geschützt. Historische Dokumente werden bei einer Menübereinigung weder gelöscht noch automatisch neu gespeichert.
